# Agent-Build

This repository contains two Python quickstarts for building and running
simple AI demos:

- [gradio-quickstart](./gradio-quickstart/README.md) contains Gradio demos,
  including a basic interface, an image-to-sketch demo, and a Qwen chat
  example.
- [langchain-quickstart](./langchain-quickstart/README.md) contains a
  LangChain example that sends a prompt to Qwen and prints the response.

Each quickstart has its own setup instructions, dependencies, and API
configuration. Follow the README in the subfolder you want to run.
